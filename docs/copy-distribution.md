# スプレッドシートのコピーで配る（作者向けの手順）

みらいコンパスは、学習記録を入れるスプレッドシートにスクリプトが束ねられた状態
（コンテナバインド）でも、独立スクリプトでも動きます。`code.gs` の `MiraiDb` が
どちらかを見分けます（`SpreadsheetApp.getActiveSpreadsheet()` が取れるかどうか）。

コピーで配ると、先生の手数が **11 ファイル貼り付け → デプロイ** から
**コピー → デプロイ** に減ります。この文書は、そのテンプレートを作る手順です。

> **この作業は、Google アカウントを持つ人にしかできません。**
> リポジトリの側からは用意できないので、ここに手順だけ置いてあります。
> テンプレートを作り直して ID が変わったときは、**5 節の3か所**を差し替えてください。

---

## 1. 貼り付けるファイルを用意する

手元で生成物を作ります。`vendor_*.html` はリポジトリにコミットされていますが、
`package.json` を更新したあとは作り直してください。

```bash
npm ci
npm run build     # vendor_css.html / vendor_icons.html / vendor_js.html
npm run ci        # 生成物のずれ・SW の版・品質ゲート・テストをまとめて見る
```

GAS に置くのは次の **11 個**です。`.claspignore` が送っているものと同じです。

| 種類 | ファイル |
|---|---|
| `.gs` 2 個 | `code.gs` / `Gemini.gs` |
| `.html` 9 個 | `index.html` / `css.html` / `js_core.html` / `js_student.html` / `js_teacher.html` / `js_worksheet.html` / `vendor_css.html` / `vendor_icons.html` / `vendor_js.html` |

> `Gemini.gs` を忘れないでください。AI でワークシートを作るところが
> `GigaGemini` を呼んでいるので、これが無いと**その機能だけが実行時に落ちます**。
> 画面には「生成に失敗しました」としか出ないので、原因にたどり着けません。

## 2. テンプレートを作る

1. 新しいスプレッドシートを作り、名前を **「みらいコンパス」** にする。
   （コピーすると「みらいコンパス のコピー」になります。先生が名前を変えても構いません。）
2. シートは作らなくてよい。**最初に開かれたときに `MiraiDb.ensure()` が
   `UnitMaster` から `Responses` までの 12 枚を作ります。**
   先に作るなら、見出し行は `code.gs` の `DB_SCHEMA` と同じにすること。
3. 「拡張機能」＞「Apps Script」を開く。
4. 既定の `コード.gs` の中身を消し、`code.gs` を貼り付ける。
   ファイル名は `コード` のままでよい（`.gs` の名前は動作に関係しません）。
5. 「＋」＞「スクリプト」で `Gemini` を作り、`Gemini.gs` の中身を貼る。
6. 「＋」＞「HTML」で9つ作り、1 節の表のとおりに名前を付けて中身を貼る。
   **名前は拡張子を除いた形**（`js_core.html` なら `js_core`）にすること。
   `index.html` が `<?!= include('js_core'); ?>` で読み込んでいるので、
   1つでも名前が違うと真っ白な画面になります。
7. いったん保存する。**デプロイはしない**（デプロイはコピーには付いてこないので、
   ここで作っても意味がありません）。

## 3. 中身を空にしておく

**テンプレートに残っているものは、コピーした全員に配られます。**

- 試しに入れた単元・名簿・学習記録・ワークシートを消す
- スクリプトのプロパティに `TEACHER_EMAILS` / `GEMINI_API_KEY` / `SS_ID` が
  残っていないか確認する（「プロジェクトの設定」＞「スクリプト プロパティ」）

> スクリプトのプロパティは**コピーされません**が、テンプレート側に残っていないことは
> 確かめておいてください。とくに `TEACHER_EMAILS` が残っていると、
> **コピーした先生が「最初の先生」になれません**（登録済みとして扱われます）。

## 4. 共有の設定

1. スプレッドシートの「共有」を開く。
2. 一般的なアクセスを **「リンクを知っている全員」＋「閲覧者」** にする。
   - **「編集者」にしないこと。** 編集者にすると、コピーせずに直接書き込めてしまいます。
3. リンクをコピーする。次の形になっているはずです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/edit?usp=sharing
   ```

4. 末尾を **`/copy`** に置きかえたものが、配るリンクです。

   ```
   https://docs.google.com/spreadsheets/d/<ファイルID>/copy
   ```

   これを開くと「コピーを作成」のダイアログがすぐ出ます。

## 5. リンクを貼ってある場所（2026-08-25 に設定済み）

配っているリンクは1つです。

```
https://docs.google.com/spreadsheets/d/1ilyPgdjv1cRY0bDhSvNafmWfjQbKl8L98ctXy3Zhjeg/copy
```

| ファイル | 場所 |
|---|---|
| `README.md` | 「A. スプレッドシートをコピーする」の手順1 |
| `docs/index.html` | 「入れかた」の節（`actions` のボタン） |
| `docs/note/mirai-compass-note-article.md` | 「導入手順」の A |

**テンプレートを作り直して ID が変わるときは、この3か所すべてを差し替えてください。**
どこか1つでも古い ID のまま残ると、そこから来た先生だけが消えたファイルを開くことになります。

## 6. 入れたあとに確かめること

手元では確かめられないので、実機で1回だけ見てください。

1. **別のアカウント**（できれば学校のアカウント）でコピーリンクを開き、
   コピーが作れるか。
   - **学校のドメインが「外部のファイルのコピー」を禁じていると、ここで止まります。**
     止まる場合は、手順 B（貼り付け）を案内し続けてください。
2. コピーしたファイルでデプロイし（実行するユーザー: 自分／
   アクセスできるユーザー: 〈学校のドメイン〉内の全員）、URL を開いて画面が出るか。
3. **ボタンを押さずに**、そのまま先生の画面が出るか（設定 ⚙ が出るか）。
   デプロイした本人が自動的に担任として登録されます
   （`MiraiAuth.ensureDeployerRegistered`）。
4. **コピーしたそのファイル**にシートが 12 枚できているか。
   （別に「みらいコンパス_データベース」ができていたら、`getActiveSpreadsheet()` が
   効いていません。コンテナバインドになっていない＝独立スクリプトに貼っています。）
5. **児童役のアカウントで先に URL を開いても、管理者にならないか。**
   登録されるのは訪問者ではなくデプロイした先生なので、順番に依存しません。
   児童役では設定 ⚙ が出ないことを確かめてください。
6. 設定 ⚙ ＞「セットアップ状況」で、「ログインの確認」が緑になっているか。
   ここが赤いときは、デプロイの「アクセスできるユーザー」がドメイン外を含んでいます。
7. コピーしたファイルの上のメニューに **「みらいコンパス」＞「シートを点検する」** が
   出るか。押して「シートの作りは想定どおりです」と出れば、見出しがそろっています。
   （このメニューは、スプレッドシートを開いたときに `onOpen` が作ります。
   独立スクリプトでは出ません。）

## 7. すでに配ってある学級について

**前の配り方（独立スクリプト）で公開済みの学級は、そのままで動きます。**
`MiraiDb.open()` は束ねられたファイルが無ければ、これまでどおり
スクリプトプロパティの `SS_ID` のスプレッドシートを開きます。学習記録は消えません。

貼り直しをお願いするのは、`code.gs` や画面の直しを届けたいときだけです。

## 8. 更新をどう届けるか

型E（先生ごとのデプロイ）にした代わりに、**更新をこちらから一斉に配れなくなりました。**

- `docs/` に置いた案内ページと PWA の外枠は、`main` にマージすればすぐ全校に届きます。
- GAS 側（`code.gs` と `.html` 9 個）の直しは、先生に貼り替えをお願いすることになります。
  シートの構造が変わる直しでは、貼り替えたあと `MiraiDb.ensure()` が
  足りない見出しを自動で足します。**先生の手作業は貼り替えだけです。**
- 列を減らす・並べ替える変更は入れないでください。
  すでに配ったファイルを機械で直す方法がありません（`MiraiDb` は足すことしかしません）。
