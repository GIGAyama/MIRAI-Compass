# note 記事の入稿メモ（みらいコンパス）

連載「教室で使えるかもしれないもの作り」に載せる紹介記事一式です。

```
docs/note/
├── mirai-compass-note-article.md   記事本文（そのまま note に貼れる形）
├── images/                          実際に操作して撮った画面 37 枚
└── README.md                        この文書
```

## 貼るまえに直すところ

1. **連載番号**。タイトル行の `#◯` を実際の番号に置きかえてください。推測で埋めると連載が壊れるので、こちらでは埋めていません。
2. **公開先の URL**。本文の「はじめに」に置いてあるのは
   `https://github.com/GIGAyama/MIRAI-Compass` です。読み手に渡したいのが
   GitHub Pages のシェル（`https://mirai-compass.giga-school.com/`）なら、そちらに差しかえてください。
   Pages が有効になっているかは Settings > Pages で確かめられます。
3. **前作への言及**。「✍️ ワークシートも、このアプリの中で配って返せます」の冒頭に
   「以前この連載で紹介した『みらいパスポート』」と書いてあります。
   その回の note のリンクを足すと、連載の読者に伝わりやすくなります。

## note への貼りかた

1. note の新規投稿を開き、タイトル欄に本文1行目（`#` を外したもの）を貼ります。
2. 本文は2行目以降をそのまま貼ります。見出し（`##`）はそのまま見出しとして入り、note が目次を自動で作ります。
3. 画像は手で1枚ずつ上げます。本文の `![...](images/xx.png)` の位置に、同じ番号の画像を挿入してください。
4. 画像の直後に置いてある一行は、note の**キャプション欄**へ移します。本文に残したままでも読めますが、キャプションに入れたほうが収まりがよくなります。
5. ハッシュタグは `#GIGAスクール` `#自由進度学習` `#小学校` `#GoogleAppsScript` `#教育ICT` あたりが合うと思います。

## 記事に書いた数字の出どころ

- **テンプレート4種と時間数**（3時間・8時間・7時間・6時間）… 単元管理モーダルの実画面（`images/03-unit-templates.png`）
- **「面積」は7時間で12件の課題**… テンプレートから作成するときの確認ダイアログの表示。作成後の `UnitMaster` シートも13行（見出し1行＋課題12件）で一致
- **8つの力**（自己管理・計画性・対話・協力・挑戦・工夫・集中・責任）… `js_core.html` の `SKILL_DEFINITIONS`（8件）
- **子どもの4タブ**… `js_student.html` の `STUDENT_NAV_TABS`
- **先生の7画面**… `js_teacher.html` の `TEACHER_VIEWS`（design / control / cards / seating / heatmap / dashboard / summaries）
- **ひろばのひとことは40文字まで**… `js_worksheet.html` の `buildPeerReactionBar`（`maxlength="40"` と `slice(0, 40)`）
- **外部から読む実行コードが無いこと**… `vendor_*.html` に実バイトを同梱。Google Fonts だけが外部で、これは書体のみ
- **データの置き場所はスプレッドシート1つ（12シート）**… `code.gs` の `DB_SCHEMA`（12キー）

README.md に載っている数字のうち、記事で使ったものはすべて上のとおりコードか実画面で裏を取っています。裏の取れなかった数字（実機での同時アクセス数など）は記事に書いていません。

## 撮影について

**すべて、実際にブラウザを操作して撮ったものです。** 合成も加工もしていません。
先生1人と子ども6人ぶんのブラウザを別々に開き、初期設定から添削・返却まで通して操作しました。
計画づくりのドラッグ、ワークシートへの書きこみ、赤ペンの丸つけも、実際の操作です。

ただし、**動かした先は Google のサーバーではありません。** この作業環境からは
`script.google.com` に到達できないため、撮影用に次の足場を用意しました。

- `code.gs` を Node の中でそのまま読み込み、`SpreadsheetApp` / `PropertiesService` /
  `LockService` / `Session` / `Utilities` / `CacheService` / `DriveApp` を、同じ形の
  メモリ上のものに置きかえた
- `index.html` の `include()` を code.gs と同じように埋めて配り、
  `google.script.run` を同じ形の呼び出しに置きかえた
- 本人確認は `?as=メールアドレス` で切りかえた（本番で `Session.getActiveUser()` が返す値にあたる）

つまり、**画面もサーバー側の処理も本物のコードのまま**で、データベースと Google 認証だけが
手もとの代役です。したがって、次の2点は記事の画面では確かめられていません。

- 実際の Google アカウントでの先生判定（`getActiveUser` の戻り値）
- 40人が同時に開いたときの速度

また、ワークシートの中身は**手貼り（AI手動コピペ）で入れたもの**です。Gemini に接続できない環境なので、
アプリが用意する指示文をそのまま使い、それに沿う HTML を人の手で書いて貼り付けました。
記事の本文でも「AIが作った」とは書いていません。API キーを登録すれば自動生成の経路が使えます。

## 撮り直すときの手順

撮影用の足場は `.tmp-shots/` に置いていましたが、**納品時に削除しています。**
撮り直すときは、次の形でもう一度用意してください。

1. `npm i --no-save playwright`
2. `code.gs` を読み込む GAS の代役（`SpreadsheetApp` などのメモリ実装）を書く
3. `index.html` の `<?!= include('x'); ?>` を展開して配るサーバーを立て、
   `google.script.run` を `fetch` に差しかえる小さな橋を `<head>` に差しこむ
4. スキルの `scripts/capture.mjs` にシナリオを渡して撮る

つまずいたところを2つだけ残しておきます。

- **`sheet.getRange('A:A')` の A1 表記**に対応しないと、`saveWorksheetToDB` が既存行を
  見つけられず、保存のたびに行が増えます。同じ taskId の行が2つできて、
  読み出し側が古いほうを拾うので「保存したのに空のまま」に見えます
- **提示モードの撮影**は、`togglePresentationMode()` を直に呼ぶのが確実です

## 文体について踏襲したこと

- 太字・斜体・表・区切り記号（矢印やスラッシュやコロン）を使っていません。確認は次で通ります

```bash
python3 - <<'PY'
import re
s = open('docs/note/mirai-compass-note-article.md', encoding='utf-8').read()
print('太字', s.count('**'), '表', len([l for l in s.split('\n') if l.startswith('|')]))
for sym in ['→', '／', '▲', '▶', '：']:
    print(sym, s.count(sym))
print('本文の字数', len(re.sub(r'!\[.*?\]\(.*?\)', '', s)))
PY
```

- 本文の字数は約7,500字です（画像の記法を除いた数）
- 箇条書きは手順のところだけにしています
- 絵文字は見出しだけです
- 見出しは基本の6本に、目玉として2本（🗓️ と ✍️）を足しました
- **教室での出来事を実体験としては書いていません。** 「こうなればいいと思って作った」
  「〜だと思います」までにとどめてあります。実際の授業のようすは、書き手が足すところです

## 公開の前に反映してほしい修正が2つあります

撮影中に、記事で紹介する機能が2か所きちんと動いていないことが分かりました。
記事とは別のコミットに分けてありますので、**公開の前にこの2つを反映してください。**

### 1. 提示モードで児童名が伏せられていなかった

`css.html` は `.student-name` を伏せる指定を持っているのに、その class が
LIVEモニター・進捗一覧・まとめ・添削の名前に付いていませんでした。
座席ビューだけが（`.seat-card .fw-bold` という別の指定で）伏せられている状態でした。
記事の「導入のメリット」で提示モードの名前伏せに触れているので、ここは直してあります。

### 2. キーボードで打った回答が、先生にも友だちにも見えていなかった

子どもがワークシートに打ちこんだ答えは `Responses` シートの `studentAnswers` に
保存されていましたが、先生の添削画面（`getSubmissionDetail`）とひろばの閲覧
（`getSharedResponses`）がそれを返していませんでした。返ってくるのは手書きだけなので、
**キーボードで書いた子の答案は、先生の画面では白紙に見えていました。**
記事はワークシートの読み合いと添削を目玉として紹介しているので、こちらも直してあります。

どちらも `npm run ci` は通っています。
